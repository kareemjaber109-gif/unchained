📡 Packet Tracer Quick Reference
📡 Cisco Router Models
Compact ISR for small offices / home offices. 2 Fast Ethernet + WIC slots for serial/WAN expansion. Very common in CCNA lab topologies.
Gen2 ISR with 2 Gigabit Ethernet ports, enhanced security (IOS firewall, IPsec VPN), and modular slots. Great for medium branch sites.
First-gen ISR, widely used in CCNA/CCNP labs. 2 onboard FE, supports WICs, HWICs, PVDMs. Perfect for serial connections & frame relay practice.
Powerful ISR G2 routers (2901 = 2 GE, 2911 = 3 GE). NAT, Zone-Based Firewall, IPsec, DMVPN. The 2911 is the workhorse of enterprise labs.
Latest gen — up to 1 Gbps throughput, 3 onboard GE (2 fixed + 1 SFP), application-aware services, Cisco IOS XE, DNA licensing.
🔀 Cisco Switch Models
Entry Layer 2 (12 or 24 FE). Classic for learning VLANs, STP, VTP. No routing — needs router-on-a-stick for inter-VLAN.
The most popular CCNA lab switch. Layer 2 with 24-48 FE/GE. Full 802.1Q VLANs, PVST+, Rapid PVST, PortFast, BPDU Guard, EtherChannel, QoS.
Multilayer switch (L2 + L3). Does Inter-VLAN Routing via SVI interfaces without a router. Supports OSPF, EIGRP, static routing. CCNP ENCOR essential.
Stackable Layer 3, successor to 3560X. IOS XE, better performance, StackWise-480, advanced security (802.1X, port security), QoS.
🔬 Router vs Switch — Quick Compare
Layer L3 (Network) — IP L2 (Data Link) — MAC; MLS = L2+L3
Job Connects different networks, routes packets Connects devices within same network / VLAN
Address IP Address (dest IP) MAC Address (dest MAC); SVI = IP on MLS
Broadcast Blocks — each port = own domain 1 domain by default; split via VLANs
Use Case Home router → ISP; WAN edge Wiring closet → PCs / servers / printers
VLANs Inter-VLAN routing via subinterfaces Creates VLANs natively; MLS routes via SVIs
Ports Few (2–8) Many (12, 24, 48, 96)
